CampusEye

ESP32-based dual-layer security system for after-hours campus monitoring (PIR motion + RFID authorization)

How it works

1. Time window

DS3231 RTC arms the system from 18:00 to 07:00, including across midnight.

2. Motion detected

HC-SR501 PIR triggers a 5-second window to present an RFID card.

3. RFID check

RC522 compares the card UID against the authorized card.

4. Alarm

No valid card: LED on and active-low buzzer beeps (300 ms on/off) for 5 seconds.
