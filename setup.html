Connect your ESP32

Steps

1. Open campuseye_wifi.ino and set your WiFi name, password and control PIN.
2. Upload it, then open Serial Monitor at 115200 baud and note the IP address it prints.
3. Make sure your phone/PC is on the same WiFi.
4. Go to the Live page, enter the IP and PIN, press Save & connect.

Important: HTTPS limitation

GitHub Pages uses https, but the ESP32 serves plain http. Browsers block https pages from calling http devices, so the live page will show OFFLINE there.

Fixes

Option A: open locally (easiest)

Download this site folder and open index.html from your computer. It can reach the ESP32 on your WiFi.

Option B: MQTT (works from GitHub)

ESP32 publishes status to an MQTT broker, and the page reads it over secure WebSockets. Ask to have this version built.

API

GET /status
GET /control?cmd=arm|disarm|stop|test&key=PIN
